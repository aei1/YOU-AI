# YOU-AI — เว็บเรียนของฉัน

เว็บแอปหน้าเดียวสำหรับเก็บบทเรียน แบบทดสอบ โน้ต และระบบคะแนนสะสม
เปิดใช้งานจริงที่ https://aei1.github.io/YOU-AI/

## แท็บในแอป

มีสามแท็บ อยู่บนแถบด้านล่างของจอ (แตะได้ถนัดมือ)

| แท็บ | ใช้ทำอะไร |
|------|-----------|
| หน้าหลัก | ยอดคะแนน (บนสุด) กระดานข้อความถึง Claude บอร์ดแจ้งเตือน สรุปความคืบหน้า และปฏิทิน (ล่างสุด) |
| โน้ต | แบ่งเป็นสองส่วนย่อย — **อ่าน**: บทเรียน (มีโหมด flashcard) และโน้ตทั่วไปอยู่ในลิสต์เดียวกัน · **กิจกรรม**: รายการภารกิจที่ได้แต้ม และแบบฝึกหัด |
| มาร์เก็ต | ใช้แต้มแลกไอเทมในชีวิตจริง เช่น ใบลาหยุด และแลกแต้มเป็นเงินตามอัตราที่ตั้งเอง |

ยอดคะแนนคงเหลือแสดงที่หน้าหลักที่เดียว หน้ากิจกรรมกับหน้ามาร์เก็ตไม่แสดงซ้ำ

### แต้มมาจากไหน

แต้มได้ตอน **ทำจริง** เท่านั้น ไม่ใช่ตอนตั้งเรื่องไว้

- อ่านบทเรียนจบ กดว่าเรียนแล้ว: +10 แต้ม (จ่ายครั้งเดียวต่อบทเรียน)
- ทำแบบฝึกหัด: +5 แต้มต่อข้อที่ตอบถูก (จ่ายครั้งเดียวต่อชุด)
- ภารกิจ: กดว่า "ทำเสร็จแล้ว" ได้แต้มตามที่ตั้งไว้

### ภารกิจ

แท็บโน้ต › กิจกรรม คือรายการภารกิจ **ตั้งภารกิจไว้ไม่ได้แต้ม** ต้องกด "ทำเสร็จแล้ว" ถึงจะได้
กดพลาดกด "ยกเลิกครั้งล่าสุด" คืนแต้มได้

เลือกได้ว่าทำซ้ำ **ครั้งเดียว / ทุกวัน / ทุกสัปดาห์ / ทุกเดือน / ทุกปี**

- ครั้งเดียว: ทำเสร็จแล้วจบ การ์ดจางลงและจมลงล่างสุด
- ทำซ้ำ: นับรอบถัดไปจากวันที่ทำล่าสุด พอถึงรอบขึ้น "ครบกำหนดแล้ว" และกดรับแต้มได้อีก (วันละครั้ง)

ทุกครั้งที่ทำจะไปโผล่บนปฏิทิน และกำหนดครั้งถัดไปถูกทำเครื่องหมายไว้ล่วงหน้าด้วยจุดสีเทา
ลบภารกิจ = คืนแต้มทุกรอบที่เคยได้ไป (ถ้ายังไม่เคยทำก็ไม่ต้องคืนอะไร)

### ค้นหาและกรองในแท็บโน้ต

ส่วน **อ่าน** มีช่องค้นหาและปุ่มกรอง 4 ปุ่ม — ทั้งหมด / อังกฤษ / จีน / โน้ต
(สองปุ่มกลางกรองเฉพาะบทเรียนตามภาษา ปุ่มสุดท้ายแสดงเฉพาะโน้ตทั่วไป)

ช่องค้นหารับทั้งคำและแท็กพร้อมกัน เช่น `#ทักทาย คำศัพท์` = ต้องมีแท็กนั้น **และ** มีคำนั้น
ส่วน **กิจกรรม** มีช่องค้นหาแบบทดสอบของตัวเอง ใช้รูปแบบเดียวกัน

แตะแท็ก `#...` ที่ไหนก็ได้ (บนหน้าหลัก ในบทเรียน ในโน้ต) จะกรองรายการอ่านให้ทันที
ส่วนแท็กในแบบทดสอบจะกรองรายการแบบทดสอบ

### บอร์ดแจ้งเตือน

โน้ตแต่ละใบบนบอร์ดกดเข้าไปได้ และจะพาไปยังสิ่งที่มันพูดถึง —
โน้ต "อ่านจบ" เปิดบทเรียนนั้น, โน้ตแบบทดสอบเปิดแบบทดสอบนั้น,
โน้ตแลกของไปหน้ามาร์เก็ต, โน้ตอีเวนต์ไปที่วันนั้นในปฏิทิน
ใบที่ไม่มีอะไรให้เปิด (เช่น ข้อความเตือนเฉยๆ) จะกางข้อความเต็มขึ้นมาแทน
และถ้าสิ่งที่อ้างถึงถูกลบไปแล้ว ก็จะกางข้อความพร้อมบอกว่าของหายไปแล้ว
มุมขวาบนของโน้ตคือปุ่ม × สำหรับลบทิ้งอย่างเดียว ไม่เปิดอะไร

### ฝากข้อความถึง Claude

หัวข้อแรกของหน้าหลักคือกระดานข้อความ พิมพ์ทิ้งไว้ได้เลยว่าอยากให้ทำอะไร
เลือกได้ว่าอยากให้มาอ่านภายใน 1 นาที / 5 นาที / ไม่รีบ

ทางเดินของข้อความ:

1. ข้อความที่พิมพ์ถูกบันทึกลง `messages` ในไฟล์ `you-ai-data.json` บน Google Drive ทันที
2. Claude อ่านไฟล์นั้นจาก Drive
3. Claude ตอบและลงมือทำ โดยเขียนลงไฟล์ `claude-outbox.json` ใน repo นี้
4. เว็บดึง `claude-outbox.json` ตอนเปิดหน้า ตอนกลับมาที่แท็บ และทุก 30 วินาที
   แล้วทำตามทีละรายการ — แต่ละรายการมี `id` จึงทำซ้ำไม่ได้

ชนิดของสิ่งที่ Claude สั่งให้เว็บทำได้ (`type` ใน `claude-outbox.json`):

| type | ทำอะไร |
|---|---|
| `reply` | ตอบกลับในกระดานข้อความ (ใส่ `replyTo` เป็น id ของข้อความที่ตอบ) |
| `note` | เพิ่มโน้ตทั่วไป (`title`, `content`, `tags`) |
| `lesson` | เพิ่มบทเรียน (`title`, `content`, `lang`, `tags`) |
| `event` | เพิ่มอีเวนต์ในปฏิทิน (`date`, `title`, `note`) |
| `notify` | ปักโน้ตแจ้งเตือนบนบอร์ด (`title`, `body`) |
| `activity` | บันทึกกิจกรรมพร้อมแต้ม (`title`, `kind`, `points`, `date`) |

**ข้อควรระวังเรื่องความเป็นส่วนตัว:** repo นี้เป็นสาธารณะ สิ่งที่ Claude เขียนใน
`claude-outbox.json` จึงเปิดให้คนอื่นเห็นได้ ส่วนข้อความที่คุณพิมพ์อยู่บน Google Drive
ของคุณเองเท่านั้น ไม่ได้ถูกอัปขึ้น repo

### แลกแต้มเป็นเงิน

หน้ามาร์เก็ตมีช่องแลกแต้มเป็นเงินอยู่บนสุด อัตราแลกเปลี่ยน **ตั้งได้ทั้งสองฝั่ง**
เป็นรูปแบบ `N แต้ม = M เงิน` พร้อมตั้งชื่อสกุลเงินเอง เช่น

- `1 แต้ม = 500 กีบ` — 1 แต้มมีค่ามากกว่า 1 หน่วยเงินก็ได้
- `20 แต้ม = 1 บาท`
- `10 แต้ม = 0.5 บาท` — ฝั่งเงินใส่ทศนิยมได้

ค่าเริ่มต้นคือ 10 แต้ม = 1 บาท ใส่จำนวนแต้มแล้วจะเห็นทันทีว่าได้เงินเท่าไหร่
กดแลกแล้วแต้มจะถูกหักและบันทึกไว้ในประวัติพร้อมอัตราที่ใช้ตอนนั้น
กดพลาดก็กดลบในประวัติเพื่อคืนแต้มได้

แลกเกินแต้มที่มี หรือแลกน้อยจนปัดแล้วได้ 0 จะถูกปฏิเสธพร้อมบอกเหตุผล

### ปฏิทิน

ปฏิทินบนหน้าหลักรวมทุกอย่างที่มีวันที่ไว้ในที่เดียว — กิจกรรมที่บันทึก บทเรียนที่เรียนจบ
แบบฝึกหัดที่ทำ การแลกของรางวัล และอีเวนต์ที่พิมพ์เพิ่มเอง (เช่น วันสอบ)
วันไหนมีอะไรจะมีจุดสีใต้ตัวเลข แตะที่วันเพื่อดูรายการของวันนั้น

## การเข้าใช้งาน

1. **ใส่รหัส PIN** — ล็อกหน้าจอแบบง่ายเหมือนปลดล็อกโทรศัพท์
   (แก้ค่า `PIN` ในไฟล์ `index.html` เพื่อเปลี่ยนรหัส) เป็นการกันสายตาคนอื่นเท่านั้น ไม่ใช่ระบบความปลอดภัยจริง
2. **เข้าสู่ระบบ Google** — เพื่อเข้าถึงข้อมูลบน Google Drive

## การเก็บข้อมูล

ข้อมูลทั้งหมดเก็บเป็นไฟล์ `you-ai-data.json` ไฟล์เดียวใน **Google Drive ของผู้ใช้เอง**
ไม่มีการเก็บข้อมูลไว้ในเครื่อง (ไม่ใช้ localStorage) จึงเปิดจากมือถือและคอมพิวเตอร์เห็นข้อมูลชุดเดียวกันเสมอ

**ข้อจำกัดที่ตามมา:** ต้องมีอินเทอร์เน็ตและเข้าสู่ระบบ Google ทุกครั้ง — ไม่มีโหมดออฟไลน์

- ใช้ OAuth scope `drive.file` เท่านั้น แอปจึงเห็นได้เฉพาะไฟล์ที่ตัวเองสร้าง ไม่เห็นไฟล์อื่นในไดรฟ์
- บันทึกอัตโนมัติแบบหน่วงเวลาเล็กน้อยหลังแก้ไข และบันทึกทันทีเมื่อปิด/สลับแท็บ
- สถานะการซิงก์แสดงที่มุมขวาบนของ header — ถ้าบันทึกไม่สำเร็จ แตะที่สถานะเพื่อลองใหม่
- ผู้ใช้เดิมที่มีข้อมูลค้างในเครื่อง ระบบจะย้ายขึ้น Drive ให้อัตโนมัติครั้งแรกที่เข้าใช้ แล้วล้างข้อมูลในเครื่องทิ้ง
- `data.json` ใน repo เป็นเพียงข้อมูลตั้งต้นสำหรับบัญชีที่ยังไม่มีไฟล์บน Drive
